## ⑥難しかった点・次回トライしたいこと（又は機能）
- リファクタリングで、むやみに作成していたメソッドを共通化することをメインに取り組んだ。共通化によって、動作順をまた考えないといけなかったり、どの箇所を共通化するかというところが難しかった。またリセット処理で、初期値にする値を見落としていたりした。
何回から記憶じゃんけんに移行するのかを最初に選ぶ画面を作って切り替えたりできたらいいなと思ったので、次回はポップアップや、モーダルの表示など他の画面を表示させるのをやってみたい。
